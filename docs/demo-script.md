# Two-minute judging demo

Preflight: run `pnpm local:doctor`, `pnpm meta:check`, then `pnpm local` with your
own eligible Meta project key in ignored `.dev.vars`. Do not show the key/editor
or provider credentials in the recording. Verify a real model receipt before
claiming the Meta workflow is demonstrated.

**0:00–0:15 — Problem.** “An arborist can receive a phone video, but still needs
clear evidence and the right questions. ArborPulse turns a capture into a
traceable inspection brief, while being explicit about what it cannot conclude.”

**0:15–0:40 — Meta before measurement.** Select a real clip or your own tripod
recording. Consent to six sampled frames, click Inspect scene with Muse Spark.
Show the proposed boxes, frame-linked concerns, and actual model receipt. Explain
that the operator confirms a rigid tree feature and a fixed reference. If the
capture is poor, show the concern rather than pretending the model found a good one.

**0:40–1:05 — Measurements.** Confirm regions, run scan. Show raw trace, spectrum,
retention, and a source frame that seeks the original video. For an explicit
known-frequency check, use the synthetic pine and identify it as synthetic.
Show camera-shake/real stress refusal: Recapture is an intended product outcome.

**1:05–1:35 — Meta after measurement.** Open Field brief, add recorder context,
generate grounded AI brief. Click a frame reference and a metric reference.
Point to the distinction among measured data, visible observations and recorder
notes. Show model/request ID, usage, prompt version, and cost estimate. Repeat
identical request to demonstrate reuse with no new paid call if useful.

**1:35–1:50 — Handoff.** Download the illustrated HTML report. Show its six
frames, measurements, attribution, questions and limitations; print to PDF.

**1:50–2:00 — Close.** “Local measurements, Meta scene understanding, auditable
interpretation. This is inspection support—not a tree-failure predictor. Our next
step is arborist-reviewed field evaluation with independent motion measurements.”

Record the actual working keyed build. Do not splice a mocked provider fixture
into the demo as if it were a real response. Keep a local backup because judging
network access can be unreliable. The current private hosted link must be shared
with judges deliberately before submission.
