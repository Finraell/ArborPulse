# ArborPulse — three-minute demo script

Prepared script. Record the actual working app; do not present synthetic scenes as field validation. The live Meta segment must use a real configured key before submission.

| Time | Screen / action | Narration |
| --- | --- | --- |
| 0:00–0:20 | Workspace, tree video visible | “Trees move in the wind, but a phone video rarely becomes usable inspection evidence. ArborPulse turns that movement into a measurable record and a better brief for an arborist.” |
| 0:20–0:40 | Open Capture guide; close it | “Capture one tree and a stationary reference. Keep the camera steady. The complete video stays on the device; you choose whether to share three frames for the AI brief.” |
| 0:40–1:05 | Riverside oak; show the two regions; Run motion scan | “This is an explicitly synthetic test clip with a known imposed response of 0.35 hertz. PhysicsLens tracks textured features and subtracts camera translation.” |
| 1:05–1:25 | Metrics, Time/Frequency toggle | “The recovered peak is about 0.33 hertz, within the resolution of this short clip. We expose the trace, spectrum, tracking retention, and raw data. Pixels are not meters, and observed response is not automatically natural frequency.” |
| 1:25–1:45 | Field context and Field brief | “A reported concern near an occupied target moves this recording earlier in the review queue. We do not turn sway into a structural risk score.” |
| 1:45–2:15 | Configured Muse Spark: consent, Generate AI notes | “Muse Spark reads the sampled frames alongside measured evidence and field notes. Its job is to draft grounded observations and useful questions for on-site inspection. Strict structured output keeps those notes reviewable. These are genuine Meta model results.” |
| 2:15–2:40 | Windy capture; run scan; show Recapture | “A persuasive report from bad footage is worse than no report. This deliberately shaking-camera fixture fails our capture-quality gate and asks for a steadier recording.” |
| 2:40–3:00 | Download brief and evidence JSON; show repository docs | “The output is portable evidence, not a black-box answer. ArborPulse pairs local physical measurement with Meta reasoning to help arborists decide what to look at next. The next step is real field validation with professionals.” |

Before recording: configure Meta access; warm the two scans if needed; ensure no real personal location, private file path, or API key is visible. Keep the final video within the submission portal’s current limit. Do not call the script a recorded demo.
