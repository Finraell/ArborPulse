## What cannot be finished honestly without outside input

1. A live Meta run using the user's eligible project key and credits. The user can
   run `pnpm meta:check`, then the two model stages; receipts are exported locally.
2. An actual demo recording of that live workflow.
3. Arborist review and diverse tripod field captures, preferably with independent
   motion measurements. Synthetic/software tests do not supply this evidence.
4. Judge access to the private repository/site, once the required audience is known.

The strongest next improvement is independent field evidence, not an invented
higher rating or adding another unverified model integration.
